#PROJECT : Creating a Webpage for a Culinary Adventure

Scenario :
Sunnydale School has a basic webpage that serves as an information hub for students, parents, and staff. The current page features general information about the school, including its mission, upcoming events, and contact details. While functional, the webpage lacks the interactive and visual appeal necessary to engage its audience fully. As a budding web developer, you have been approached by the school to revamp this webpage.

Your task is to apply your HTML knowledge to enhance the page's aesthetics, usability, and interactivity, making it a more inviting and informative resource for the Sunnydale community.

## Objective

Build a simple webpage using html concepts introduced in this module

## Features

## Features

- Styled webpage using internal and inline CSS
- Organized content with headings and sections
- Color-coded section headings for improved readability
- Highlighted upcoming event dates
- Interactive contact information with tooltips
- Event listings with custom data attributes
- Styled sections using IDs and CSS classes
- Grouped contact information in a dedicated container
- Clean and responsive page layout

## What I've learned

Throughout this module and project :

- Styling
- Layout
- Global Attributes
- Event and Data Atrributes

## Reflection

## Reflection

This project helped me develop a better understanding of HTML and basic CSS by applying styles to web page elements, organizing content with IDs and classes, using HTML attributes effectively, and improving the overall appearance and usability of a webpage. It also reinforced the importance of creating clean, consistent, and user-friendly web designs.
